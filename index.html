Conhecendo o CSS

O que é CSS?

CSS (Cascading Style Sheets) é uma linguagem de estilo utilizada para definir a apresentação de documentos HTML. Ele permite separar o conteúdo da apresentação, facilitando a manutenção e a personalização do visual de um site.

Como trabalhar com CSS?

O CSS é trabalhado através da definição de regras de estilo que são aplicadas aos elementos HTML. Essas regras podem ser definidas em arquivos externos, internos ou inline, permitindo flexibilidade na forma como os estilos são aplicados.

  • CSS Externo: Utiliza arquivos .css separados, que são vinculados ao HTML através da tag <link>.
  • CSS Interno: Define estilos dentro da tag <style> no cabeçalho do documento HTML.
  • CSS Inline: Aplica estilos diretamente nos elementos HTML através do atributo style.
